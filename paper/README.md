## Historical notes on this snapshot


*At the time of this snapshot* this directory was the durable copy of the paper while
Overleaf git access was unavailable. It compiled the manuscript of that date from this
directory alone.

## Compile it

```bash
cd paper
latexmk -pdf -interaction=nonstopmode main.tex   # run TWICE: bibtex needs the second pass
```

**Verified 2026-10-02** by copying this directory to a scratch location and
building there: exit 0, **0 undefined control sequences, 0 undefined citations,
0 undefined references, 11 pages**, and the rendered text is **byte-identical**
to the Overleaf working copy's own PDF (65,268 characters, md5-equal after
`pdftotext`). The PDFs differ only in embedded timestamps.

> ⚠️ On a *first* build you will see ~40 undefined citations and ~52 undefined
> references. That is normal — bibtex has not run yet. The second pass clears
> them. Do not "fix" anything on the strength of a single pass.

## What is here

| file | role |
|---|---|
| `main.tex` | the manuscript — single file, no `\input` of section files |
| `figdata.tex` | **every number and plot coordinate**, generated by `scripts/make_figures.py`. Never edit by hand |
| `p1refs.bib` | the project's bibliography |
| `sample.bib` | template bibliography, retained because the class example references it |
| `aamas.cls`, `ACM-Reference-Format.bst` | AAMAS 2027 class and bibliography style |
| `aamas27-logo-small.jpg`, `by.eps`, `by.pdf` | class assets |
| `AAMAS_2027_sample.{tex,pdf}` | the untouched template, kept as provenance |
| `ARTIFACT_LOOKUP.md` | paper → artifact map for a reader starting from the manuscript |
| `main.pdf` | the current build, for reference |

There are **no figure image files**: every figure is TikZ drawn inline in
`main.tex` from macros in `figdata.tex`. That is why the package is this small
and why a figure cannot drift from its artifact.

## 🔴 This is a MIRROR, not a fork

The Overleaf project `git.overleaf.com/6abbde4a9eb777031afef068` **remains the
target remote** and must not be replaced. When access returns:

1. `cd ../../overleaf && git fetch origin`
2. reconcile only if the remote moved (it should not have),
3. `git push origin main` — the local clone is **ahead by one commit**,
4. fresh-clone the project elsewhere, compile it, and verify the title,
   tables, figures and `ARTIFACT_LOOKUP.md` against this directory.

**Do not re-apply manuscript edits by hand from this mirror.** The local
Overleaf clone at `../../overleaf` already contains them; pushing it is the
whole operation. Re-applying would duplicate integrated content.
