What Is This Memory Useful For?

Measuring Task-Conditioned Utility in Long-Term Agent Memory

Chih-Hsuan Yang1*, Anjir Ahmed Chowdhury2*, Feng Yan2, Rajeev Thakur1

1 Argonne National Laboratory2 University of Houston* Equal contribution

Paper Code Dataset

What is a stored memory useful for?

A writer stores each past page visit without ever seeing a future task; later, a frozen reader answers each question twice with identical context, once with the memory and once without it. On LongMemEval-V2 factual-recall tasks, the effect is strongly task-conditioned: within the same memory, answer-bearing task pairs gain +0.33 more reward than matched controls, and the contrast stays positive across sessions, positions and readers. Task-blind summaries and structured records gain less than the raw text, even at a fixed total context, and generic retrieval finds answer-bearing memories far above chance but misses most of them.
