Agent memory systems increasingly score each stored item by how useful it is and keep the highest-scoring ones. That design treats usefulness as a scalar property of the item, when the operative question for a stored experience is narrower: what is this memory useful for? Recent work has observed that the same memory can help one future task and harm another, but reports it categorically, from a single execution per pair, and for one way of writing the memory down.

We evaluate long-term agent memory conditionally. For each past episode we construct three representations of the same experience, without letting the writer see any future task: a faithful extractive span, an abstractive summary, and a structured experience record. Each memory is evaluated against several distinct future tasks by paired re-execution of a frozen agent, with and without that memory available, holding the model, cluster, decoding, context budget, and scoring fixed between arms, and repeating conditions to estimate an execution-noise floor.

This yields a profile across future tasks rather than one score. We treat sign changes as descriptive rather than diagnostic, since a memory can help one task and harm another under a purely additive account, and instead separate the variance attributable to the memory, to the task, and to their interaction, comparing observed reversals against those additivity alone predicts. We pair every utility measurement with its cost in stored tokens, exposed tokens, latency, and calls, charging each representation for forming it, and summarize the result as a memory utility-efficiency frontier.

We evaluate on a long-term agent-memory benchmark and a scientific coding benchmark, and release the resulting conditional memory utility dataset.
